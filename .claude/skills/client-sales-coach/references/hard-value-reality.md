# 硬实力现实评估

> **话术不能逆天改命。**
> 客户不会因为你会说话，就买一个解决不了他问题的产品；也不会因为一个 PPT 做得漂亮，就相信一家没有交付能力的公司。
> 这一章帮你诚实评估：**你和你的产品，能打什么段位的客户。**

---

## 一、先认清一个事实

B2B 销售的成交，本质是三个变量的乘积：

```
成交 = 产品匹配度 × 客户决策条件 × 关系与信任
```

- **产品匹配度**（占 50%）：你的产品能不能解决客户的核心问题、满不满足硬性要求。
- **客户决策条件**（占 30%）：有没有预算、有没有时间窗口、决策链通不通。
- **关系与信任**（占 20%）：客户信不信你、愿不愿意为你承担风险。

**话术只在第三项里起作用，而且只能放大前两项。** 前两项不成立，关系再好也签不了，签了也交付不了。

---

## 二、产品硬实力清单（逐项打分 0–100）

| 维度 | 你要回答的问题 | 自评 |
|---|---|---|
| **功能匹配** | 客户前三大痛点，产品能覆盖几个？覆盖到什么程度？ | |
| **行业案例** | 同行业、同规模、同场景的案例有几个？能不能说出名字和效果数据？ | |
| **资质合规** | 客户招标要求的资质、认证、信创适配，你有吗？ | |
| **交付能力** | 实施团队多少人？同规模项目最长/最短交付周期？ | |
| **服务保障** | 响应时效、驻场能力、故障兜底机制，写不写进合同？ | |
| **集成能力** | 能不能对接客户现有的 ERP/HR/财务/钉钉/飞书/自研系统？ | |
| **价格竞争力** | 你的价格在同档产品里处于什么位置？有没有能让利的空间？ | |
| **品牌与背书** | 客户圈子里认不认你？有没有同行/上级单位用过？ | |
| **资金与账期** | 能不能承受长账期、验收后付款、垫资实施？ | |
| **生态与合作** | 有没有渠道、集成商、咨询公司帮你一起打单？ | |

**判定**：
- 8 项 ≥ 70 分：可以打中大型客户，重点在方案和关系。
- 5–7 项 ≥ 70 分：打中型客户，避开对资质/案例要求极高的央国企标。
- < 5 项 ≥ 70 分：先打中小客户和细分场景，别硬冲大标。

> 这张表不是让你自卑，是让你**别把时间浪费在打不赢的标上**。

## 三、客户"段位"与匹配关系

| 客户段位 | 典型特征 | 你需要具备 |
|---|---|---|
| **小微企业**（<100 人） | 预算低（几万）、决策快（老板一句话）、要便宜好用 | 标准化产品、低实施成本、快速交付 |
| **中型企业**（100–1000 人） | 预算中等、有 IT 部门、要比价、要案例 | 行业案例、实施方案、基础集成能力 |
| **大型集团**（1000 人+） | 预算大、周期长、多组织、要招投标、要信创 | 集团级案例、交付团队、资质齐全、生态伙伴 |
| **央国企/政府** | 合规第一、招标流程、要资质、要本地化、要安全 | 资质、信创适配、等保、驻场服务、资金承受力 |

**匹配原则**：
- **不要用小产品打大标**：资质、案例、交付能力任何一项缺失，你连入围都进不去。
- **不要用大产品打小客户**：价格和复杂度会直接劝退。
- **找到你的"甜点区"**：你的产品在哪个段位、哪个行业、哪个场景里，是"最合适"而不是"最便宜"或"最全"。

## 四、什么时候必须承认"这单不在射程内"

出现以下情况，**诚实告诉用户别硬追**，或者只做关系维护：

1. **核心需求产品做不到**：客户要定制开发/私有化深度改造/特定行业合规，你满足不了。
2. **预算差距超过 50%**：不是"再谈谈"能解决的，是产品定位不匹配。
3. **硬性资质缺失**：招标要求明确写了你没有的资质/案例/认证。
4. **客户已与对手深度绑定**：联合开发、股权关系、多年框架协议。
5. **决策人明确偏好国际大厂/指定品牌**：这不是关系能扭转的。
6. **客户要求源码交付/无限定制**：你的商业模式撑不住。

**正确表达**：
> "这单我建议你别投入太多。他们的核心需求是 XX，我们产品做不到，硬接下来交付会出问题。可以保持关系，等他们有 XX 需求的时候再进。"

**这才是专业，不是认输。**

## 五、销售个人硬价值（别只评估产品）

客户信不信你，一半看公司，一半看**你这个人**。

| 维度 | 表现 | 自评 |
|---|---|---|
| **行业语言** | 能不能用客户的词说话（KPI、流程、合规、组织架构） | |
| **案例储备** | 能不能随口讲 10 个同行案例，带数字 | |
| **方案能力** | 能不能独立写出一版有针对性的方案框架 | |
| **演示能力** | 能不能按客户场景演，而不是念功能 | |
| **职业形象** | 着装、守时、名片、邮件格式、会后纪要 | |
| **跟进纪律** | 承诺的事是否 100% 兑现、是否主动同步进度 | |
| **情绪稳定** | 被拒绝、被压价、被放鸽子后是否还能专业应对 | |
| **复盘习惯** | 是否定期复盘赢单/丢单 | |

**加分项**：懂客户业务 > 懂产品功能。能跟客户聊他的行业趋势、竞争对手、组织难题，比背产品参数值钱十倍。

---

## 六、"话术不能逆天改命"的三条铁律

1. **产品解决不了的问题，话术解决不了。** 客户要的是结果，不是你的口才。
2. **没有预算和时间窗口，关系再好也签不了。** 你能做的是等窗口、造窗口，不是催。
3. **交付不了的承诺，签了就是灾难。** 销售最大的坑是"先签下来再说"，最后毁的是公司口碑和你自己的职业信用。

---

## 七、自检：你的"段位"在哪

回答三个问题：

1. **我最擅长打哪类客户？**（行业 + 规模 + 场景，越具体越好）
2. **我打得赢的理由是什么？**（案例？价格？交付？关系？产品独特性？）
3. **我打不赢的客户长什么样？**（列出 3 类，以后见到就早止损）

**能清楚回答这三个问题，比多背 100 句话术有用。**

---

## 八、一句话

**认清自己的射程，把子弹打在该打的地方。**
专业销售的第一能力，不是"把不可能说成可能"，是"判断什么值得打"。
