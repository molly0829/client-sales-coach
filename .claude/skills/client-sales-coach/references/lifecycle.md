# 销售全周期路线图与阶段诊断（流程 C）

> 一句话：**每个阶段都有"退出标准"。没达到标准就往下走，就是在裸奔。**

---

## 全周期图

```
自我建设（底座，贯穿始终）
    │  产品理解 · 行业认知 · 案例库 · 方案能力 · 个人专业形象 · 交付口碑
    ▼
线索 ──→ 触达 ──→ 需求挖掘 ──→ 方案评估 ──→ 商务谈判 ──→ 签约 ──→ 交付与续约
 │         │          │              │              │         │          │
 名单    破冰信任    痛点预算      价值共识别     价格条款    合同回款   口碑增购
 覆盖率  30秒说清    决策链        竞品对位       招投标      赢单复盘   转介绍
```

**最容易死人的地方是「需求挖掘」**：客户说"挺好，有需要联系你"，然后你等三个月，项目给了别人。

---

## 各阶段详解

### 1. 线索（Leads）

- **目标**：持续产出"有需求、有预算、能接触"的客户名单，保证覆盖率。
- **关键动作**：行业聚焦、招投标平台监控、老客户转介绍、协会/展会、渠道与生态伙伴、竞争对手客户反挖。
- **线索质量标准**（四条至少满足两条）：有明确痛点、有信息化预算、有决策窗口、能接触到关键人。
- **退出标准**：拿到对接人姓名与联系方式，并完成第一次有效沟通（对方知道你是谁、为什么找他）。
- **常见死法**：名单里全是"没预算、没人管、没计划"的三无客户，跑断腿也签不了。
- **时间预期**：无固定，覆盖量决定上限。每月新增有效线索 ≥ 一个合理目标。

### 2. 触达（Contact）

- **目标**：让客户愿意见你、愿意让你进他的信息圈。
- **关键动作**：30 秒价值陈述、带钩子的第一条消息、同行案例、免费但有用的东西（行业诊断、方案思路、对标分析）。
- **退出标准**：完成第一次拜访或线上深度沟通（≥ 30 分钟），客户主动说了自己的现状或痛点。
- **常见死法**：一上来讲产品、群发广告、只加微信不约见、被前台/门卫挡在门外。
- **时间预期**：1–4 周。超过 4 周仍约不到人，回到线索池，别硬耗。

### 3. 需求挖掘（Discovery）—— 最危险的瓶颈

- **目标**：摸清四件事——**真痛点、预算、决策链、时间窗口**。
- **关键动作**：SPIN 提问（现状—问题—影响—收益）、现场调研、找内部教练、画决策链地图、确认立项流程。
- **退出标准**（四条全部满足才算过关）：
  1. 说得出客户的**前三大痛点**，以及不解决的业务损失（最好能量化）；
  2. 知道**预算有没有、多少、什么时候批**；
  3. 见到或至少锁定**最终决策人**；
  4. 有**明确的采购时间节点**（立项会、招标日、上线需求日）。
- **常见死法**：只跟对接人聊得很热，永远见不到老板；客户一直"再看看"；把客户礼貌当进展。
- **时间预期**：1–3 个月。超过 3 个月四要素还缺两项，按 `damage-control.md` 评估是否降级。

### 4. 方案评估（Solution）

- **目标**：让客户在"选型对比表"里把你排在第一位。
- **关键动作**：针对性方案（不是通用 PPT）、Demo 剧本（按客户场景演，不按功能模块演）、POC/试点、同行案例、价值量化（省多少人、多少天、多少风险）、技术答疑。
- **退出标准**：客户内部的选型意见倾向你，或至少把你列入短名单（2 家以内）；客户愿意让你参与需求/参数讨论。
- **常见死法**：通用方案一稿打天下；Demo 变成功能朗诵；被对手的技术参数框死；只讲功能不讲钱。
- **时间预期**：2 周–2 个月。

### 5. 商务谈判（Negotiation）

- **目标**：在保住利润和交付可行性的前提下，把价格、条款、付款、范围谈拢。
- **关键动作**：报价策略（锚点、阶梯、打包）、压价应对、付款条件、验收标准、招投标文件应对、法务评审。
- **退出标准**：价格与范围达成一致、合同进入审批流程、付款节点明确。
- **常见死法**：一压就降、降价不降范围、答应超范围服务、付款条件全是验收后、陪标陪到最后才知道。
- **时间预期**：2 周–2 个月（招投标项目按公告节点走）。

### 6. 签约（Win）

- **目标**：合同签章、首款到账、项目启动会开起来。
- **关键动作**：合同条款核对（范围/工期/验收/违约）、内部资源锁定、交付团队交接、客户高层见面。
- **退出标准**：合同生效 + 首付款到账。
- **常见死法**：销售承诺交付团队不认账；合同范围模糊，交付时扯皮；签了但首款拖半年。
- **时间预期**：1–4 周。

### 7. 交付与续约（Deploy & Renew）

- **目标**：交付口碑 → 增购 → 续约 → 转介绍。
- **关键动作**：里程碑管理、关键用户培训、阶段性汇报（给客户领导看成果）、满意度回访、二次需求挖掘。
- **退出标准**：验收通过 + 客户愿意做案例/转介绍。
- **常见死法**：签完就撒手、交付延期无人沟通、客户内部换人后关系断掉。
- **时间预期**：3–12 个月（视项目规模）。

## 阶段与赢单概率的粗略对应

| 阶段 | 赢单概率参考 | 说明 |
|---|---|---|
| 线索 | 1–5% | 只是名单 |
| 触达 | 5–15% | 建立了联系 |
| 需求挖掘（四要素全） | 20–40% | 有了竞争资格 |
| 方案评估（进短名单） | 40–60% | 有相对优势 |
| 商务谈判 | 60–80% | 只剩价格和流程 |
| 签约 | 90%+ | 只差签字 |

> 这些数字是**校准工具**，不是精确预测。用途是：当你说"这单有 7 成把握"时，对照一下——四要素齐了吗？进短名单了吗？没进就别报 7 成。

## 阶段诊断：八个问题

回答"我现在该干嘛"时，逐条问：

1. **痛点**：客户最疼的三件事是什么？不解决会损失什么（钱/时间/风险）？
2. **预算**：有没有？多少？什么时候批？谁批？
3. **决策链**：最终拍板的是谁？谁是反对者？谁是你的教练？
4. **时间窗口**：客户什么时候必须做决定？这个时间点是谁定的（政策/预算/上级/竞争对手）？
5. **竞争**：还有谁在跟？客户更倾向谁？为什么？
6. **差异化**：客户选你而不是别人的**唯一理由**是什么？（"我们功能全"不是理由）
7. **下一步**：上一次沟通结束时，约定的下一步动作是什么？执行了吗？
8. **关系深度**：你见到的最高层级是谁？他愿不愿意为你说话？

**诊断规则**：1–4 题里有 2 题答不上来 → 阶段实际停留在"需求挖掘"，别自我感觉良好。第 6 题答不上来 → 你在陪跑。第 7 题答不上来 → 你在做无效社交。

---

## 阶段倒退怎么办

客户从"方案评估"退回"需求挖掘"、从"商务谈判"退回"方案评估"，是常态，不一定是丢单。处理原则：

1. **先查原因**：是决策人换了、预算砍了、竞品降价了、还是你某个承诺没兑现？
2. **不要装没事继续往前推**：退回哪个阶段，就补哪个阶段的标准动作。
3. **及时更新档案和概率**，别抱着旧判断做新决策。
4. 如果退回原因是"客户内部结构性问题"（如集团统一采购、预算冻结），按 `damage-control.md` 评估是否降级维护。
