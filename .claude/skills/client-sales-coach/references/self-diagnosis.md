# 销售自我诊断系统

> 客户不是问题，**你的短板才是**。
> 本工具帮你把"我签不了单"拆成"我具体缺什么"，然后按性价比排序去补。

---

## 一、能力雷达（10 项，每项 0–100 自评）

先自评，再用下面的"评分标准"校准。**诚实打分才有用。**

| # | 能力 | 说明 | 自评 |
|---|---|---|---|
| 1 | **线索质量** | 能否持续找到"有痛点、有预算、能接触"的客户 | |
| 2 | **破冰触达** | 30 秒说清"我是谁、找你干嘛、对你有什么用" | |
| 3 | **需求提问** | 会不会 SPIN，能不能让客户说出真心话 | |
| 4 | **业务理解** | 是否懂客户行业和岗位的 KPI、痛点、语言 | |
| 5 | **方案呈现** | 方案是否针对客户，Demo 是否演场景而非念功能 | |
| 6 | **异议与压价** | 能否接住"太贵了/别家便宜/你们不行"而不乱阵脚 | |
| 7 | **决策链经营** | 能否见到决策人、培养教练、识别反对者 | |
| 8 | **推进节奏** | 每次沟通能否拿到明确的下一步 | |
| 9 | **多客户管理** | 能否并行跟 10+ 客户而不混乱、不断片 | |
| 10 | **复盘习惯** | 丢单/赢单后是否结构化复盘 | |

### 评分标准

- **80–100**：在这项上你比多数同行强，能带人。
- **60–79**：及格，能应付常规场景，遇到硬仗会掉链子。
- **40–59**：明显短板，正在丢单但你没意识到。
- **0–39**：致命短板，现在就应该停下手上的活去补。

> **经验值**：销售丢单的原因 80% 集中在 #1、#3、#7、#8 四项。先把这四项打到 70 分，比把 #5 从 80 提到 90 有用得多。

## 二、沟通习惯自测（逐条打勾，打勾越多越好）

**触达阶段**
- [ ] 我能在 30 秒内说清我的价值主张，不用"我们公司成立于……"
- [ ] 我的第一条消息里有一句"针对你行业/你岗位"的具体内容
- [ ] 我不群发广告，每条消息都改了称呼和场景

**需求挖掘阶段**
- [ ] 上次拜访，客户说的话比我多（目标：客户 70%）
- [ ] 我能说出客户当前最疼的三件事
- [ ] 我问过"如果不解决，一年会损失什么"
- [ ] 我问过预算和时间节点
- [ ] 我知道最终拍板的是谁

**方案阶段**
- [ ] 我的方案第一页写的是客户的业务问题，不是我们的公司介绍
- [ ] Demo 按客户场景演，不按功能菜单念
- [ ] 我给过客户"能拿去汇报"的一页纸材料

**商务阶段**
- [ ] 我报价前问过对比口径（范围/年限/服务）
- [ ] 客户压价时我先谈价值再谈价格，没有第一时间降
- [ ] 我清楚自己的底价和不可让的条款

**推进**
- [ ] 每次沟通结束我都有明确的 Next Step（谁、做什么、什么时候）
- [ ] 我的客户档案里，每个客户都有"下一步动作 + 日期"
- [ ] 我不会连续两周对同一个客户"无事可做"

**自查**：如果某一段打勾少于一半，那就是你当前最该补的环节。

## 三、拜访习惯自检（每次拜访后 5 分钟）

1. 我这次拜访的**目标**是什么？达成了吗？
2. 客户主动说了哪些**内部信息**（预算/人事/竞品/时间）？
3. 我见到了**最高层级**是谁？比上次高了吗？
4. 客户问了哪些**问题**？问题背后在担心什么？
5. 结束时我约定了什么**下一步**？
6. 这次拜访让我对"赢单概率"的判断**上调还是下调**？为什么？

> 如果第 3 题连续三次没进步，说明你的关系经营在"横向铺"而不是"纵向打"。

## 四、时间分配诊断（一周复盘）

把上周时间按下面分类打勾，看比例：

| 类别 | 应占比例 | 你的实际 |
|---|---|---|
| 新线索开发 / 陌拜 / 转介绍 | 20–30% | |
| 需求挖掘与方案（高概率客户） | 30–40% | |
| 商务谈判与投标 | 15–20% | |
| 老客户维护 / 续约 / 转介绍 | 10–15% | |
| 内部协调（售前、交付、法务） | 10% | |
| 无效陪标 / 低概率客户 | **≤ 5%** | |

**红线**：如果"无效陪标/低概率客户"超过 15%，你就是在用战术勤奋掩盖战略懒惰。

## 五、短板定位 → 改进优先级

按这个顺序补，性价比最高：

1. **先补"信息能力"**（#1 线索、#3 提问、#7 决策链）——这些决定你打的是不是"能赢的仗"。
2. **再补"推进能力"**（#8 节奏、#6 异议）——决定你能不能把仗打完。
3. **最后补"呈现能力"**（#5 方案、#2 破冰）——决定你打得漂不漂亮。

**不要一上来就学话术。** 话术是最后 10%，前面的信息判断错了，话术再好也是白费。

## 六、30 / 60 / 90 天改进计划（模板）

**第 1 个月：看清现状**
- 给手上所有客户做一次六维评估（见 `damage-control.md`），砍掉 0–2 分的。
- 每个客户补一张决策链地图。
- 记录一周时间分配。

**第 2 个月：补齐信息**
- 每周至少 2 次深度需求挖掘（带 SPIN 问题清单）。
- 每个高概率客户至少约到一次中层以上会面。
- 建立自己的行业案例库（10 个可讲的案例，含数据）。

**第 3 个月：提升推进**
- 每次沟通强制留 Next Step。
- 练习报价与压价应对（找同事角色扮演）。
- 复盘 3 个最近的丢单，写清"死因"。

## 七、一句话

**销售的天花板不是话术，是认知。**
你越懂客户的业务、越懂自己的产品边界，话就越少，单反而越大。
