使用 `client-sales-coach` 技能处理下面的内容。

## 用户输入

$ARGUMENTS

## 执行要求

1. **先读**技能主文件 `.claude/skills/client-sales-coach/SKILL.md`，按其中的「路由」判断走哪条流程。
2. **判断输入类型**：
   - 是聊天记录/邮件/会议纪要/拜访记录 → 走 **流程 A（客户沟通分析）**，必读 `references/chat-analysis.md`，按「定位 → 信号解读 → 你的问题 → 建议回复 → 下一步动作」五段输出。
   - 是具体销售问题（找线索/破冰/报价/竞品/催单等）→ 走 **流程 B（知识问答）**，按需查 `references/knowledge-base.md`。
   - 是"这单还有没有戏/要不要继续跟/下一步干嘛" → 走 **流程 C（阶段诊断）**，查 `references/lifecycle.md` 与 `references/damage-control.md`。
3. **涉及具体客户时**：
   - 回复开头加一行阶段标签：`【<代号> · 阶段：X · 赢单概率约 N 成 · ↑/→/↓】`
   - 先看 `profiles/` 里有没有该客户的档案；没有就先建，按 `references/profile-template.md` 的字段。
   - 首次建档要把档案完整展示一次，并询问是否保存到 `profiles/<代号>.md`。
4. **给出可复制的回复**：标明渠道（微信/邮件/电话稿），内容能直接发出去，并说明意图与预期反应。
5. **诚实**：没戏就说没戏，缺信息就说缺什么，不要为了"鼓励"而美化判断。
6. **合规底线**：不提供行贿、围标、伪造材料、骚扰等内容；不承诺产品做不到的事；不贬低竞品。
