# 客户沟通分析方法论（流程 A 必读）

> 输入：客户微信聊天记录、邮件往来、会议纪要、拜访记录、电话录音转写稿。
> 输出：定位 → 信号解读 → 你的问题 → 建议回复 → 下一步动作。

---

## 一、分析前必须先做的两件事

1. **确认这是哪个客户**（代号 + 行业 + 规模）。没有档案就先建档，见 `profile-template.md`。
2. **确认最近一次互动的背景**：谁先找谁、多久没联系、上一轮谈到哪。脱离上下文的一句"好的，谢谢"没有任何信息量。

如果用户只丢了三五句话、什么背景都没有，先问：

> 这客户什么行业、大概多少人？见过面吗、见的是谁？之前给过方案或报价没有？

---

## 二、信号标注体系（解读时逐条打标）

在逐条解读时，用下面的标签，让用户一眼看懂：

| 标签 | 含义 | 典型话术 |
|---|---|---|
| ♨️ **真兴趣** | 客户在为你投入时间/资源，是推进信号 | "你们下周能来做个演示吗""能不能给我们讲讲 XX 集团是怎么用的""我们明年有个信息化预算""你把方案发我，我给我们领导看看" |
| 🙂 **客套** | 礼貌性回应，零信息量，别当进展 | "好的谢谢""方案我看了，挺全面的""有需要再联系你""辛苦你了""你们做得不错" |
| 🎣 **压测/试探** | 试探你的底线、实力或诚意 | "别家报价只有你一半""你们公司是不是人不多""能不能先免费做一版给我们看看""你们能保证三个月上线吗" |
| ❄️ **隐性拒绝** | 表面没拒绝，实际已关上门 | "我们今年暂时没这个计划""等我们 ERP 上完再说""领导最近太忙，一直没时间""这个事你找下我们小张吧"（且不再引荐） |
| ⚠️ **内部动态** | 客户组织内部的变化，比话术本身更重要 | 对接人换人、对接人降级、突然要你补一堆材料、突然加快/放慢节奏、"我们集团要统一采购了" |
| 💰 **预算信号** | 钱的信息 | "预算还没批""今年预算用完了""这个项目在集团层面立项" |
| 👥 **决策链信号** | 人的信息 | "这个要我们老板拍板""我们 CIO 比较看重 XX""采购部要统一走流程" |
| ⏰ **时间信号** | 何时必须决策 | "我们下个月要定""Q4 必须上线""招标文件下周发" |

**解读原则**：
- 一句话可能同时有两个标签（如"方案我看了，挺好，有需要联系你" = 🙂客套 + ❄️隐性拒绝）。
- **不要过度解读单句话**，要看"他是否在为你付出成本"——时间、内部关系、预算流程。愿意带你见领导、愿意给你内部信息，才是真兴趣。
- 客户越客气，越要警惕；客户越挑刺、越问细节，反而可能越认真（挑刺是在做尽调）。

## 三、五步输出法

### 1. 📍 定位

一行讲清：阶段 + 赢单概率 + 趋势 + 依据。

> **示例**：客户已进入需求挖掘后期，赢单概率约 4 成、↓降温。依据：两周前主动约了演示（♨️），但演示后只回了"挺好"（🙂），且今天把对接人从信息中心主任换成了行政专员（⚠️降级）。

判断阶段的标准见 `lifecycle.md` 的"阶段退出标准"，不要凭感觉。

### 2. 🔍 信号解读

逐条引用原话 + 打标 + 一句解释。**重点不是翻译字面意思，而是翻译"这句话背后的动作"**。

> 客户："你们这个 OA 跟我们现在的钉钉比，优势在哪？"
> → **🎣 压测 + ♨️ 真兴趣**：他在拿最熟悉的竞品做基准，说明他在认真选型（真兴趣），同时也在试你会不会只会贬低对手（压测）。**千万别一上来就踩钉钉**，先承认钉钉在协同上的优势，再切到"流程审批、合同、印章、集团管控、信创合规"这些钉钉覆盖不到的地方。

### 3. ⚠️ 你的问题

只讲有证据的问题，按严重程度排序，最多 3 条。常见错误清单（B2B 版）：

- **需求感过重**：一天三个电话、消息秒回、客户不回就焦虑追问——在 B2B 里这会被读成"你不缺客户但我很缺单"。
- **只讲产品，不问业务**：说了 40 分钟功能，没问过一句"你们现在最头疼什么"。
- **过早报价**：需求没摸清就报价，客户只会拿你的价格去压别家。
- **过晚报价**：客户已经要立项了，你还在"我们再深入了解一下"，进度被对手抢走。
- **越级找死**：绕过对接人直接找老板，得罪教练，老板一句话"你跟小张对接"就把你打回来。
- **被压价就乱让步**：客户一说"太贵"就降价/送服务，暴露价格虚高，后面还会继续砍。
- **没有 Next Step**：每次聊完都很愉快，但从不约定"下一步谁在什么时间做什么"。
- **承诺过度**：为了签单答应"什么都能做""一个月上线"，交付时爆炸。
- **答非所问**：客户问"能不能跟我们现有系统打通"，你回"我们功能很全"。
- **陪聊不推进**：跟对接人关系很好，但永远见不到决策人，永远在"再等等"。

### 4. 💬 建议回复

**给 1 个主推 + 至多 1 个备选**，标明渠道（微信/邮件/电话），内容要**能直接复制**。

回复构造四要素（缺一不可）：

1. **目的**：这条消息要拿到什么（约见面？确认预算？推动立项？）
2. **身份**：你是顾问不是推销员——用"我们看了下你们的情况，有个想法"而不是"我们产品很好"。
3. **信息量**：给一样他无法拒绝的东西（同行案例、一份针对性分析、一个他能拿去汇报的材料）。
4. **下一步**：明确的动作 + 时间（"周三下午我带方案过来 30 分钟，您看方便吗"）。

**反例**（常见错误）：
> "王总您好，上次方案看了吗？有什么问题随时问我，我们产品肯定能满足您需求。"

问题：只催不问、无新信息、把"满足需求"当结论、没有下一步。

**正例**：
> "王总，上次演示后我复盘了一下，你们目前最卡的是合同审批和用章两条线，正好 XX 集团（同行业、同规模）去年也是从这两块切入的，我把他们的落地过程整理成了一页纸。这周三或周四下午我过来 30 分钟，跟您和张经理一起过一下，看能不能对上你们的节奏？"

### 5. 🎯 下一步动作

给 1–3 个**本周内可执行**的动作，并说清"为什么是它"：

- 约见决策人（怎么约、约谁、带什么）
- 补信息（预算、时间、竞品、决策链）
- 培养教练（给对接人"能拿去汇报"的材料）
- 制造时间窗口（政策/预算周期/对手动作）
- 止损（若触发 `damage-control.md` 的止损线）

## 四、不同输入源的处理差异

| 输入 | 特别注意 |
|---|---|
| 微信记录 | 看回复速度、字数对比、谁主动、表情与语气变化；语音转文字要标注"可能有误"。 |
| 邮件 | 看抄送了谁（决策链暴露）、回复时长、是否走正式流程、称呼变化。 |
| 会议纪要 | 看谁没来、谁打断谁、谁做总结、下一步责任人是不是你。 |
| 拜访记录 | 看客户带你去了哪（会议室/车间/展厅）、见了谁、留你多久。 |
| 电话录音稿 | 看谁说得更多（客户说 70% 才是好拜访）、客户问的问题类型。 |

## 六、几条硬规矩

1. **只分析给到的内容，不脑补客户没说的事**。信息不足就明说"这里判断不了，需要你补 X"。
2. **不美化**。客户没预算就说没预算，别把"再研究研究"翻译成"有戏"。
3. **给判断，也给判断的依据**，让用户能自己复核。
4. **涉及具体人名/公司名时提醒脱敏**：聊天记录里出现真实姓名、电话、报价，建议用户改代号再存盘。
