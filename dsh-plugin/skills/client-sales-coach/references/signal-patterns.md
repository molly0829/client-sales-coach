# 信号识别增强库

> 销售里最贵的错误不是"说错话"，是**"把客套当意向，把压价当成交"**。
> 本库帮你把客户每句话归到正确类别，并给出应对动作。

---

## 一、真兴趣信号（客户在为你付出成本）

判断标准只有一个：**他是否在为你投入时间、内部关系、流程资源**。嘴上说"好"不算。

### 弱信号（有戏，但别激动）

- 主动问"你们跟 XX 比怎么样"——开始做选型对比。
- 问细节参数、部署方式、集成能力、实施周期。
- 愿意加你微信、留私人手机号。
- 回复速度变快、字数变多、开始用"我们"（"我们这边打算……"）。

### 中信号（可以往前推）

- 主动约演示、约上门、约电话。
- 要同行案例、要客户名单（愿意为核实而花时间）。
- 带你参观现场、介绍其他部门的人认识。
- 开始吐槽现状（"现在的系统太老了""每次审批要跑三趟"）——**吐槽是真兴趣的最高级形态之一**，他在向你暴露弱点。

### 强信号（该踩油门了）

- 主动说预算、立项、招标时间（"我们 Q3 要立项""预算大概这个数"）。
- 把你引荐给决策人，或安排你参加内部会议。
- 问你"如果我们上了，多久能见效""你们团队能驻场吗"——已经在想落地。
- 主动帮你说话（"我跟我们领导提了你们"）。
- 要求签保密协议、要正式报价单、要走供应商入库——进入采购流程。

### 应对原则

- **弱信号**：给价值，别催单。继续喂案例和信息。
- **中信号**：加速推进，约下一步，开始摸预算和决策链。
- **强信号**：立刻锁定时间窗口，同步内部资源（售前、交付），别让流程空转。

## 二、客套信号（零信息量，千万别当进展）

- "方案我看了，挺好的/挺全面的。"（没说哪里好、没提问题 = 没看或不想评价）
- "有需要再联系你。"
- "我们内部再研究研究。"
- "你们做得不错，保持联系。"
- "辛苦你了/麻烦了。"
- 群发式的节日祝福、点赞。
- 只回表情包、只回"收到"。

**为什么危险**：这些让销售产生"关系不错"的错觉，然后连续几周不推进，最后项目被别人拿走。

**正确动作**：客套之后必须**制造一个具体问题**去换真实信息。例如：

> "谢谢王总。我这边正好在整理同行业的落地清单，想确认一下：你们现在最想先解决的是审批效率，还是合同和用章这块？我按这个方向把材料做细一点。"

## 三、压测/试探（客户在试你的底线、实力、诚意）

### 1. 价格试探

- "别家报价只有你一半。"
- "能不能再便宜点，便宜我就定了。"
- "你们这个价格，我们预算不够。"

**本质**：多数时候不是真嫌贵，是在试你**会不会慌、会不会自己先降**。你一降，他就知道还有空间。

**应对**：先问清对比口径（范围/年限/服务是否一致），再谈价值，最后才谈价格。**绝不第一时间降价**（见 `knowledge-base.md` 报价章节）。

### 2. 实力试探

- "你们公司是不是规模不大？"
- "你们在我们这个行业有案例吗？"
- "你们能保证三个月上线吗？"
- "出了事谁负责？"

**应对**：不回避、不吹牛。用**可核实的事实**回答（案例、资质、团队规模、服务响应机制），做不到的明确说"做不到，但我们可以……"。**过度承诺是最大的雷。**

### 3. 诚意/投入试探

- "能不能先免费给我们做一版方案？"
- "你们先来给我们做个培训，免费的。"
- "先试用半年，好用再付钱。"

**应对**：区分"合理的售前投入"和"白嫖"。可以给**有价值的轻量投入**（一次诊断、一页对标分析），但**不做完整方案、不做免费实施**。用交换条件："方案可以做，但需要先跟您和业务部门聊 1 小时，确保不是通用模板。"

### 4. 边界试探

- "这个能不能顺便帮我们做了？"（超范围）
- "付款能不能全部验收后？"
- "你们能不能先垫资？"

**应对**：明确边界，给出替代方案。边界一旦破，后面全是坑。

## 四、隐性拒绝（表面没拒绝，实际已关门）

按危险程度排序：

| 等级 | 信号 | 翻译 |
|---|---|---|
| ⚠️ 轻度 | "等我们 XX 项目上完再说" | 优先级不在你身上，时间未定 = 没有时间 |
| ⚠️ 轻度 | "领导最近太忙"（连续两次以上） | 不想安排见面，或领导不重视 |
| ⚠️⚠️ 中度 | "你把资料发我，我看看"（只要资料不见面） | 收集信息，不打算推进 |
| ⚠️⚠️ 中度 | 把你转给更低层级的人，且不再引荐 | 你在决策链上被降级 |
| ⚠️⚠️⚠️ 重度 | "今年没这个计划/预算用完了" | 明确关闭，除非预算周期重开 |
| ⚠️⚠️⚠️ 重度 | "我们已经定了别家" | 出局，只能做长期关系 |
| ⚠️⚠️⚠️ 重度 | 不回消息 3 次以上、电话不接 | 用沉默投票 |

**处理原则**：轻度 → 换切入点再试一次；中度 → 找其他入口（教练/其他部门/上级）；重度 → 停止投入，转维护关系（见 `damage-control.md`）。

## 五、内部动态信号（比话术重要十倍）

- **换对接人**：新来的人不认你 = 关系清零，要重新破冰。
- **对接人降级**：从主任变专员，说明你在他上级那里没被认可。
- **突然要补材料**：可能在走供应商入库或合规审查（好信号，配合）。
- **突然加快节奏**：可能有上级压力或政策节点（好信号，全力配合）。
- **突然放慢**：预算、人事、战略调整（坏信号，要问原因）。
- **提到"集团统一采购/统一平台"**：单点项目可能被收编，打法要改成集团层面。
- **提到"我们请了咨询公司/第三方评估"**：进入正式选型流程，要按评分表准备。

## 六、决策链信号（五类角色）

| 角色 | 特征 | 你要做的 |
|---|---|---|
| **决策者**（老板/总经理/董事长） | 关心钱、风险、战略，不关心功能 | 讲业务结果和同行案例，讲"不上会怎样" |
| **把关者**（CIO/信息中心主任/IT 经理） | 关心技术、集成、安全、运维 | 讲架构、集成方案、运维保障、信创合规 |
| **使用者**（业务部门/HR/财务/行政） | 关心好不好用、会不会增加工作量 | 讲场景、演示、上手速度 |
| **影响者**（采购/财务/法务） | 关心流程、合规、付款 | 讲资质、条款、发票、验收标准 |
| **教练**（内部支持你的人） | 愿意给你内部信息、帮你说话 | 给他"能拿去汇报"的材料，保护他不背锅 |

**识别信号**：
- "这个要我们老板拍板" → 决策者存在但你没见到。
- "我们采购部要走流程" → 影响者会卡你，提前准备资质材料。
- "我们信息中心比较看重 XX" → 把关者有关键权重。
- "我跟我们领导提了你们" → 教练出现，立刻加码维护。

## 七、时间与预算信号

**时间信号**（出现即意味着窗口）：
- "我们下个月要定""Q4 必须上线""招标文件下周发""年底前要把预算花完"。
- 政策节点、行业检查、上级考核时间。

**预算信号**：
- "预算还没批"（= 没有时间表，风险高）
- "今年预算用完了"（= 要么等明年，要么找其他科目）
- "这个项目在集团层面立项"（= 周期长，但金额大）
- "我们预算就这么多"（= 有上限，要调方案范围而不是硬降价）

## 八、反向信号：越挑刺越可能是真客户

- 客户挑你毛病、追问细节、要求现场验证 → 在做尽调，**真兴趣**。
- 客户说"都挺好""没什么问题" → 要么没看懂，要么不想买。

**规律**：**愿意花时间挑刺的客户，比一直说好的客户靠谱得多。**

## 九、常见误判对照表

| 别把 | 当成 | 实际是 |
|---|---|---|
| "方案挺好" | 认可 | 客套，没看或不想评价 |
| "我们研究研究" | 在走流程 | 优先级低，时间未定 |
| "价格再谈谈" | 快成交了 | 可能在用你压对手价 |
| "你先发资料" | 有意向 | 收集信息，白嫖风险 |
| 见到对接人 | 见到决策人 | 差着 2–3 层 |
| 聊得开心 | 关系好 | 社交愉快 ≠ 采购推进 |
| 客户夸你专业 | 会选你 | 夸完可能选了便宜的 |
| 客户不回消息 | 在忙 | 大概率已经出局 |
